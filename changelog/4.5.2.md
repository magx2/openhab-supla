## 4.5.2

Released version 4.5.2 - jSupla 6.0.2 protocol compatibility

### Changed

- Updated the native server dependency to jSupla `6.0.2` for current SUPLA protocol definitions.
- Adapted native action trigger configuration responses to the expanded protocol structure.
- Exposed native thermal protection and input activation settings as device properties when reported by the device.

### Fixed

- Corrected decoding of native channel battery state so it is no longer interpreted as battery health.
